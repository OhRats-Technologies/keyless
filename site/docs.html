Keyless Documentation

Installation, hardware setup, local speech models, and current platform status for Linux.

Install

Run the installer script. On Debian and Ubuntu it installs the self-contained .deb package via apt; on other Linux distributions it installs the AppImage for your user. Both verify published SHA256SUMS.

curl -fsSL https://keyless.ohrats.party/install.sh | sh

The .deb installs under /opt/keyless, adds the /dev/uinput udev rule, registers a desktop entry, and includes an optional systemd user unit.

Requirements

  • Linux x86_64, PipeWire or PulseAudio, and writable /dev/uinput.
  • One or two stable V4L2 cameras. Two cameras give full stereo accuracy; one camera runs a supported mono fallback.
  • CPU-only local speech recognition by default (Parakeet TDT 0.6B v2 int8). No CUDA toolkit required.

First run

Launch Keyless from your application menu. First run walks through a resumable guided setup:

  1. Welcome — what Keyless does and how it stays private
  2. Devices — permissions, camera/mic checks, and the pinned offline speech model (downloaded in the background with progress)
  3. Calibration — a short gaze-calibration overlay
  4. Ready — start listening

Step order and completion are owned by the engine, so the macOS and Linux apps show the same guided setup and resume in place after a restart.

CLI & diagnostics

Use the CLI to inspect hardware readiness or dry-run without emitting input events:

keyless doctor
keyless doctor --json
keyless models status
keyless run --dry-run

Privacy & models

Camera frames, speech recognition, and command history stay on your machine. Network access is only used when downloading pinned model weights or if you explicitly configure an external AI provider.

Platform status

Linux and macOS The Linux PySide6 shell and the native SwiftUI macOS host share the same engine-owned setup flow and control plane. Windows (SendInput, Media Foundation, UI Automation) is not implemented yet.
